\section{Introduction}

The \texttt{oandm.py} script calculates operations and maintenance (O\&M) costs for a transmission line project. It computes annual and lifetime costs for conductors, converters, structures, and vegetation management, then calculates present values.

\section{Method Overview}

\subsection{Purpose}

This script calculates O\&M costs by:
\begin{enumerate}
    \item Loading O\&M cost parameters by component (conductor, converter, structure, vegetation)
    \item Calculating annual costs per component
    \item Computing lifetime nominal costs
    \item Calculating present values of annual O\&M payments
\end{enumerate}

\subsection{Calculation Approach}

The O\&M cost calculation follows this structure:

\begin{align}
\text{Conductor Annual} &= \text{Cost/Mile/Year} \times \text{Total Miles} \\
\text{Converter Annual} &= \text{Cost/Mile/Year} \times \text{Total Miles} \quad \text{(DC only)} \\
\text{Structure Annual} &= \begin{cases}
\text{Cost/Structure/Year} \times \text{Total Structures} & \text{(Overhead)} \\
\text{Cost/Mile/Year} \times \text{Total Miles} & \text{(Other)}
\end{cases} \\
\text{Vegetation Annual} &= \sum_{\text{terrains}} \text{Cost/Mile/Year}_{terrain} \times \text{Miles}_{terrain} \\
\text{Total Annual} &= \text{Conductor} + \text{Converter} + \text{Structure} + \text{Vegetation} \\
\text{Lifetime Nominal} &= \text{Annual} \times \text{Project Lifetime} \\
\text{Present Value} &= \sum_{t=1}^{N} \frac{\text{Annual}}{(1 + r)^t}
\end{align}

\subsection{Inputs and Outputs}

\textbf{Inputs:}
\begin{itemize}
    \item Project technical details (construction type, AC/DC, capacity, conductor type, converter type)
    \item Physical details (total miles, terrain distribution)
    \item O\&M cost parameters (conductor, converter, structure, vegetation management)
    \item Financing parameters (WACC for present value)
    \item Project lifetime
\end{itemize}

\textbf{Outputs:}
\begin{itemize}
    \item Annual costs by component
    \item Lifetime nominal costs by component
    \item Present value costs by component
    \item Total annual, nominal, and PV costs
\end{itemize}

\textbf{Parameters:}
\begin{itemize}
    \item \texttt{construction\_type} (str): Type of construction
    \item \texttt{ac\_dc} (str): AC or DC designation
    \item \texttt{capacity\_mw} (float): Capacity in megawatts
    \item \texttt{conductor\_type} (str): Type of conductor
    \item \texttt{converter\_type} (str): Type of converter
\end{itemize}

\textbf{Returns:}
\begin{itemize}
    \item \texttt{variable\_conductor\_cost\_per\_mile\_year} (float): Variable conductor cost per mile per year
\end{itemize}

\subsection{\texttt{load\_converter\_om\_costs(construction\_type, ac\_dc, capacity\_mw, conductor\_type, converter\_type)}}

Loads converter O\&M costs from YAML file. Returns 0 for AC projects.

\textbf{Parameters:}
\begin{itemize}
    \item \texttt{construction\_type} (str): Type of construction
    \item \texttt{ac\_dc} (str): AC or DC designation
    \item \texttt{capacity\_mw} (float): Capacity in megawatts
    \item \texttt{conductor\_type} (str): Type of conductor
    \item \texttt{converter\_type} (str): Type of converter
\end{itemize}

\textbf{Returns:}
\begin{itemize}
    \item \texttt{variable\_converter\_cost\_per\_mile\_year} (float): Variable converter cost per mile per year (0 for AC)
\end{itemize}

\subsection{\texttt{load\_structure\_om\_costs(construction\_type, ...terrain\_miles...)}}

Loads structure O\&M costs and calculates total costs. For overhead projects, calculates total structures by terrain and applies cost per structure. For other construction types, uses cost per mile.

\textbf{Parameters:}
\begin{itemize}
    \item \texttt{construction\_type} (str): Type of construction
    \item Multiple terrain mile parameters (forested, scrubbed\_flat, wetland, etc.)
\end{itemize}

\textbf{Returns:}
\begin{itemize}
    \item \texttt{variable\_structure\_cost\_per\_mile\_year} (float): Structure cost per mile per year (for non-overhead)
    \item \texttt{variable\_structure\_cost\_per\_year} (float): Total structure cost per year
    \item \texttt{structure\_dict} (dict): Dictionary of structure counts by terrain
    \item \texttt{total\_vegetation\_management\_cost\_per\_year} (float): Total vegetation management cost per year
\end{itemize}

\begin{lstlisting}
# Calculate structures by terrain

\section{Key Implementation Details}

\subsection{Structure O\&M for Overhead Projects}

For overhead projects, structure O\&M is calculated based on the number of structures, which varies by terrain type. The script:
\begin{enumerate}
    \item Calculates structures per terrain based on structures per mile
    \item Sums to get total structures
    \item Multiplies by cost per structure per year
\end{enumerate}

\subsection{Vegetation Management}

Vegetation management costs are terrain-specific and only apply to overhead projects. The script multiplies terrain-specific costs per mile by miles in each terrain type.

\subsection{Converter O\&M}

Converter O\&M costs only apply to DC projects. For AC projects, the function returns 0.

\subsection{Present Value Timing}

O\&M costs start at year 1 (beginning of operation) and continue for the project lifetime. The present value calculation discounts these annual payments back to the base year.

\subsection{Component-Level Tracking}

The script tracks costs at the component level (conductor, converter, structure, vegetation) for detailed analysis and reporting.
