\section{Introduction}

The \texttt{insurance\_costs.py} script calculates operational insurance costs and, when enabled, wildfire liability insurance costs for transmission line assets. Operational premiums are based on insurable asset value (conductors, structures, converters) and are paid annually over the project lifetime. Wildfire liability uses a rate-on-line (ROL) formula: annual premium = ROL $\times$ liability limit. Both are written to the batch summary (operational via \texttt{add\_insurance\_costs}; wildfire liability via \texttt{add\_wildfire\_liability\_costs}, with zeros when disabled).

\section{Method Overview}

\subsection{Purpose}

This script calculates insurance costs by:
\begin{enumerate}
    \item Loading project details and constructing category via \texttt{build\_category\_string}; loading build costs via \texttt{build\_costs.load\_costs} to get conductor/structure/converter costs with contingencies
    \item Determining insurable asset value from which components are insured (\texttt{insurable\_components}; default all)
    \item Applying premium rate from \texttt{premium\_by\_construction\_type} or default \texttt{premium\_rate}
    \item Calculating annual premium and lifetime nominal cost for operational insurance
    \item Optionally calculating wildfire liability premium (ROL $\times$ liability limit) when \texttt{insurance.wildfire\_liability.enabled} is true
    \item Calculating present value of annual premiums (payment start at COD) for both operational and wildfire liability
    \item Writing \texttt{add\_insurance\_costs} and \texttt{add\_wildfire\_liability\_costs} (zeros when wildfire liability disabled), then \texttt{write\_batch\_summary}
\end{enumerate}

\subsection{Calculation Approach}

The insurance cost calculation follows this structure:

\begin{align}
\text{Insurable Value} &= \sum_{\text{insured components}} \text{Component Cost with Contingencies} \\
\text{Annual Premium} &= \text{Insurable Value} \times \text{Premium Rate} \\
\text{Lifetime Nominal Cost} &= \text{Annual Premium} \times \text{Project Lifetime} \\
\text{Present Value} &= \sum_{t=\text{COD}}^{\text{COD}+T-1} \frac{\text{Annual Premium}}{(1 + r)^t}
\end{align}
where $T$ is the project lifetime, $r$ is the real WACC discount rate. The first payment year is COD (Commercial Operation Date) = delay\_years + construction\_years + 1, i.e.\ the first year after construction ends.

\textbf{Wildfire liability (when enabled):} Annual premium = \texttt{rate\_on\_line} $\times$ \texttt{liability\_limit}; nominal lifetime cost = annual premium $\times$ project\_lifetime; PV same as above starting at COD. Returns \texttt{None} if \texttt{wildfire\_liability.enabled} is false or parameters invalid.

\subsection{Inputs and Outputs}

\textbf{Inputs:}
\begin{itemize}
    \item Build costs (conductor, structure, converter with contingencies) via \texttt{build\_costs.load\_costs}
    \item Insurance configuration from \texttt{load\_insurance\_details} (04\_insurance): \texttt{insurance.insurable\_components}, \texttt{premium\_by\_construction\_type}, \texttt{premium\_rate}; \texttt{insurance.wildfire\_liability.enabled}, \texttt{liability\_limit}, \texttt{rate\_on\_line}
    \item Project technical details (construction type, project lifetime, delay years, construction years)
    \item Financing parameters (WACC for present value)
\end{itemize}

\textbf{Outputs:}
\begin{itemize}
    \item Operational: insurable value, annual premium, premium rate, nominal lifetime cost, PV total (via \texttt{add\_insurance\_costs})
    \item Wildfire liability: when enabled, same metrics plus liability limit and rate-on-line (via \texttt{add\_wildfire\_liability\_costs}); when disabled, zeros written
\end{itemize}

\section{Key Functions}

\subsection{\texttt{calculate\_insurance\_costs(insurance\_yaml, conductor\_cost\_with\_contingencies, structure\_cost\_with\_contingencies, converter\_cost\_with\_contingencies, construction\_type, project\_lifetime)}}

Calculates operational insurance costs based on insurable asset value.

\textbf{Parameters:}
\begin{itemize}
    \item \texttt{insurance\_yaml} (dict): Loaded insurance YAML data
    \item \texttt{conductor\_cost\_with\_contingencies} (float): Conductor cost with contingencies
    \item \texttt{structure\_cost\_with\_contingencies} (float): Structure cost with contingencies
    \item \texttt{converter\_cost\_with\_contingencies} (float): Converter cost with contingencies
    \item \texttt{construction\_type} (str): Type of construction (overhead, underground, subsea)
    \item \texttt{project\_lifetime} (int): Project lifetime in years
\end{itemize}

\textbf{Returns:}
\begin{itemize}
    \item Dictionary containing:
    \begin{itemize}
        \item \texttt{insurable\_value} (float): Total insurable asset value
        \item \texttt{annual\_premium} (float): Annual insurance premium
        \item \texttt{premium\_rate} (float): Premium rate applied
        \item \texttt{nominal\_lifetime\_cost} (float): Total lifetime cost in nominal terms
    \end{itemize}
\end{itemize}

\textbf{Key Logic:}
\begin{lstlisting}
# Calculate insurable value based on which components are insured
insurable_value = 0.0
if components.get("conductors", True):
    insurable_value += conductor_cost_with_contingencies
if components.get("structures", True):
    insurable_value += structure_cost_with_contingencies
if components.get("converters", True):
    insurable_value += converter_cost_with_contingencies

# Get premium rate (construction type specific or default)
premium_rate = premium_by_type.get(
    construction_type.lower(), 
    ins_cfg.get("premium_rate", 0.002)
)

# Calculate annual premium
annual_premium = insurable_value * premium_rate
nominal_lifetime_cost = annual_premium * project_lifetime
\end{lstlisting}

\subsection{\texttt{calculate\_wildfire\_liability\_premium(insurance\_yaml, project\_lifetime)}}

Calculates wildfire liability insurance premium using rate-on-line (ROL). Returns \texttt{None} if \texttt{insurance.wildfire\_liability.enabled} is false or \texttt{liability\_limit} / \texttt{rate\_on\_line} $\leq$ 0.

\textbf{Returns:} Dict with \texttt{liability\_limit}, \texttt{rate\_on\_line}, \texttt{annual\_premium}, \texttt{nominal\_lifetime\_cost}, or \texttt{None}.

\textbf{Key logic:}
\begin{lstlisting}
if not wildfire_liability.get("enabled", False):
    return None
liability_limit = wildfire_liability.get("liability_limit", 0)
rate_on_line = wildfire_liability.get("rate_on_line", 0)
if liability_limit <= 0 or rate_on_line <= 0:
    return None
annual_premium = rate_on_line * liability_limit
nominal_lifetime_cost = annual_premium * project_lifetime
return {"liability_limit": ..., "rate_on_line": ..., "annual_premium": ..., "nominal_lifetime_cost": ...}
\end{lstlisting}

\subsection{\texttt{main()}}

Main execution function that orchestrates the insurance cost calculation and output.

\textbf{Workflow:}
\begin{enumerate}
    \item Loads project technical details; constructs category via \texttt{build\_category\_string}; gets \texttt{number\_of\_converters} from \texttt{get\_project\_data\_raw} if DC
    \item Loads build costs via \texttt{load\_costs(category, total\_miles, number\_of\_converters, contingencies, reconductoring)}; loads insurance via \texttt{load\_insurance\_details()}
    \item Calls \texttt{calculate\_insurance\_costs(...)} and \texttt{calculate\_wildfire\_liability\_premium(insurance\_yaml, project\_lifetime)}
    \item \texttt{insurance\_start\_year} = \texttt{calculate\_cod\_year(delay\_years, construction\_years)}; \texttt{insurance\_pv} = \texttt{calculate\_present\_value(annual\_premium, wacc\_real, project\_lifetime, insurance\_start\_year)}; same for wildfire liability PV if enabled
    \item \texttt{add\_insurance\_costs(csv\_results)}; \texttt{add\_wildfire\_liability\_costs(...)} (with zeros when disabled); \texttt{write\_batch\_summary()}
\end{enumerate}

\section{Example}

The following example demonstrates a typical usage of the insurance cost calculation:

\begin{lstlisting}
# Example: 500 MW Overhead AC line
# Category: "Overhead/AC/500MW/Advanced Aluminum/NA"
# 
# Inputs:
#   - Conductor cost (with contingencies): $55M
#   - Structure cost (with contingencies): $25M
#   - Converter cost: $0 (AC project)
#   - Premium rate: 0.2% (overhead construction)
#   - Project lifetime: 50 years
#   - Payment start: Year 3 (after 2-year construction)
#
# Calculation:
#   Insurable value = $55M + $25M + $0 = $80M
#   Annual premium = $80M * 0.002 = $160,000
#   Lifetime nominal = $160,000 * 50 = $8M
#   Present value = $160,000 * PV annuity (50 years, 3% discount) = $4.2M
#
# Output:
#   - Insurable value: $80M
#   - Annual premium: $160,000
#   - Lifetime nominal: $8M
#   - Present value: $4.2M
\end{lstlisting}

\section{Key Implementation Details}

\subsection{Insurable Components}

The script allows configuration of which components are insurable (conductors, structures, converters). By default, all components are insured, but this can be customized in the YAML configuration.

\subsection{Premium Rate by Construction Type}

Different construction types may have different premium rates. The script first checks for a construction-type-specific rate, then falls back to a default rate if not specified.

\subsection{Payment Timing}

Insurance premiums start at Commercial Operation Date (COD), which is the first year after the delay and construction periods (COD = delay\_years + construction\_years + 1). Premiums are paid annually for the project lifetime.

\subsection{Discount rate and perspective}

Operational and wildfire liability insurance PV use the \textbf{real WACC} (utility/private perspective). The resulting PV is a private cost to the utility. CTCC can report both societal-cost PV (e.g.\ wildfire expected loss in file 06, which uses the social discount rate) and utility-cost PV (insurance); totals that combine them are hybrid unless interpreted accordingly.

\subsection{Wildfire Liability}

Wildfire liability insurance covers the \textbf{insured} portion of wildfire risk. The wildfire cost module (file 06) uses \textbf{uninsured} severity (residual damages), so including both this module and wildfire liability insurance does not double-count. Wildfire liability is optional and controlled by \texttt{insurance.wildfire\_liability.enabled} in the insurance YAML. When enabled, annual premium = \texttt{rate\_on\_line} $\times$ \texttt{liability\_limit}. The script always writes \texttt{add\_wildfire\_liability\_costs} (with zeros when disabled) so batch summary columns remain consistent.

\subsection{AFUDC Treatment}

Operational insurance is not AFUDC-eligible because it is an operating expense, not a construction cost. Only construction-period costs are eligible for AFUDC capitalization.

\subsection{Dependency on Build Costs}

This script requires build costs to be calculated first (via \texttt{build\_costs.py}) to determine insurable asset values. It imports and calls \texttt{load\_costs()} from \texttt{build\_costs.py}.
