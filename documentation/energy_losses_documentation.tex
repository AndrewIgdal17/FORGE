\section{Introduction}

The \texttt{energy\_losses.py} script calculates transmission line losses and converter losses for a given project configuration. It exposes \texttt{get\_total\_energy\_losses()} as the main entry point (used by \texttt{line\_loss\_costs.py} and \texttt{emissions.py}) and can be run standalone to print results. For reconductoring projects it uses the old configuration's voltage (towers unchanged) and the new configuration's resistance (new conductors).

\section{Method Overview}

\subsection{Purpose}

This script calculates energy losses by:
\begin{enumerate}
    \item Loading project technical and physical details
    \item Building category identifier (\texttt{build\_category\_string}); for reconductoring, also building old category for voltage lookup
    \item Loading circuit and resistance details for the (new and, if reconductoring, old) category
    \item For reconductoring: using old voltage and new resistance; for greenfield: using new config throughout
    \item Calculating phase current (\texttt{calculate\_phase\_current}), full load adjustment (\texttt{full\_load\_adjusted})
    \item Calculating line losses (\texttt{calculate\_line\_losses}) and converter losses (\texttt{calculate\_converter\_losses}; DC only)
    \item Returning a dict of losses and inputs; standalone run displays results via \texttt{print\_results}
\end{enumerate}

\subsection{Calculation Approach}

The energy loss calculation follows this structure:

\textbf{Line Losses:}
\begin{align}
I_{phase} &= \frac{P}{\sqrt{3} \times V \times N_{circuits}} \quad \text{(AC)} \\
I_{phase} &= \frac{P}{V \times N_{poles}} \quad \text{(DC)} \\
P_{loss} &= I^2 \times R \times N_{phases} \times N_{circuits} \\
\text{Losses (MWh/year)} &= P_{loss} \times \text{Full Load Adj} \times 8760
\end{align}

\textbf{Converter Losses (DC only):}
\begin{align}
P_{converter} &= P \times \text{Utilization} \times \text{Loss Rate} \\
\text{Converter Losses (MWh/year)} &= P_{converter} \times 8760
\end{align}

\subsection{Inputs and Outputs}

\textbf{Inputs:}
\begin{itemize}
    \item Project technical details (construction type, AC/DC, capacity, conductor type, converter type, line utilization, converter loss percentage; for reconductoring: old capacity, old conductor, old AC/DC)
    \item Physical details (line length via \texttt{load\_physical\_details})
    \item Circuit and resistance details (via \texttt{load\_circuit\_and\_resistance\_details} for category; YAML keys: voltage, conductors per phase, phases, circuits/poles, AC\_75\_resistance, DC\_20\_resistance)
\end{itemize}

\textbf{Outputs:}
\begin{itemize}
    \item Line losses (MW/mile, MWh/year, percentage)
    \item Converter losses (MW, MWh/year, percentage)
    \item Total losses (line + converter)
    \item Lifetime losses
\end{itemize}

\subsection{Integration with Other Scripts}

This script integrates with:
\begin{itemize}
    \item \texttt{smart\_loaders.py} --- \texttt{load\_project\_technical\_details}, \texttt{load\_physical\_details}, \texttt{load\_circuit\_and\_resistance\_details}, \texttt{get\_project\_data\_raw}
    \item \texttt{calculation\_utils.py} --- \texttt{build\_category\_string}, \texttt{get\_converter\_type}, \texttt{calculate\_phase\_current}, \texttt{full\_load\_adjusted}, \texttt{calculate\_line\_losses}, \texttt{calculate\_converter\_losses}, \texttt{to\_percent}

\end{itemize}

\section{Key Functions}

\subsection{\texttt{get\_total\_energy\_losses()}}

Returns a dictionary of line and converter losses and inputs for the current project. For reconductoring, uses old configuration's voltage and new configuration's resistance.

\textbf{Returns:}
\begin{itemize}
    \item \texttt{losses\_mwh\_per\_year}, \texttt{lifetime\_losses\_mwh}, \texttt{losses\_mw\_per\_mile}, \texttt{resistance\_per\_mile}, \texttt{line\_loss\_per\_mile\_percent}, \texttt{total\_line\_loss\_mw}, \texttt{total\_line\_loss\_percent}
    \item \texttt{total\_converter\_losses\_mw}, \texttt{total\_converter\_losses\_mwh}, \texttt{converter\_loss\_percent}
    \item \texttt{total\_losses\_mwh\_per\_year}, \texttt{project\_lifetime}, \texttt{voltage\_kv}, \texttt{phase\_current}, \texttt{full\_load\_adj}, \texttt{line\_length}, and other circuit parameters
\end{itemize}

\textbf{Key Logic:}
\begin{lstlisting}
new_category = build_category_string(project_details=project_details)
if project_details.reconductoring:
    old_category = build_category_string(construction_type, old_ac_dc, old_capacity, old_conductor, old_converter)
    old_circuit = load_circuit_and_resistance_details(old_category)
    voltage_kv = old_circuit.voltage_kv
    new_circuit = load_circuit_and_resistance_details(new_category)
    # use new_circuit for resistance and counts
else:
    circuit = load_circuit_and_resistance_details(new_category)
    voltage_kv = circuit.voltage_kv
    # ...

phase_current = calculate_phase_current(capacity_mw, voltage_kv, number_of_phases, number_of_circuits_poles, ac_dc)
full_load_adj = full_load_adjusted(project_details.line_utilization)
# calculate_line_losses(...), calculate_converter_losses(..., converter_loss_percentage=project_details.converter_loss_percentage)
\end{lstlisting}

\subsection{\texttt{print\_results(...)}}

Prints organized results in sections (system configuration, line losses, converter losses, summary). Used by \texttt{main()} when run standalone.

\subsection{\texttt{main()}}

Calls \texttt{get\_total\_energy\_losses()}, then \texttt{print\_results(...)} with the returned dict and project details.

\section{Example}

The following example demonstrates a typical usage:

\begin{lstlisting}
# Example: 500 MW Overhead AC line
# Category: "Overhead/AC/500MW/Advanced Aluminum/NA"
# 
# Inputs (from YAML):
#   - Capacity: 500 MW
#   - Voltage: 345 kV
#   - Conductors per phase: 2
#   - Number of phases: 3
#   - Number of circuits: 1
#   - AC resistance (75°C): 0.05 ohms/mile
#   - Line utilization: 70%
#   - Line length: 100 miles
#   - Project lifetime: 50 years
#
# Calculation:
#   Phase current = 500 MW / (√3 × 345 kV × 1) = 837 A
#   Full load adj = 0.7² = 0.49
#   Line loss = (837² × 0.05 × 3 × 1) × 0.49 = 51.4 MW
#   Line loss % = 51.4 / 500 = 10.3%
#   Losses MWh/year = 51.4 × 8760 = 450,000 MWh/year
#   Lifetime losses = 450,000 × 50 = 22.5M MWh
#
# Output:
#   - Line loss: 0.514 MW/mile
#   - Line loss %: 10.3%
#   - Losses MWh/year: 450,000
#   - Lifetime losses: 22.5M MWh
\end{lstlisting}

\section{Key Implementation Details}

\subsection{AC vs. DC Calculations}

The script handles both AC and DC systems:
\begin{itemize}
    \item \textbf{AC}: Uses $\sqrt{3}$ factor, resistance at 75°C
    \item \textbf{DC}: No $\sqrt{3}$ factor, resistance at 20°C
\end{itemize}

\subsection{Full Load Adjustment}

The full load adjustment accounts for the fact that losses are proportional to current squared, and average current is less than peak current due to utilization. The adjustment is typically $u^2$ where $u$ is the utilization factor.

\subsection{Converter Losses}

Converter losses only apply to DC projects and are calculated in \texttt{calculation\_utils.calculate\_converter\_losses} based on number of converters, converter type, line utilization, capacity, and \texttt{converter\_loss\_percentage} from project details.

\subsection{Resistance Values}

The script uses different resistance values:
\begin{itemize}
    \item \textbf{AC}: Resistance at 75°C (operating temperature)
    \item \textbf{DC}: Resistance at 20°C (reference temperature)
\end{itemize}

\subsection{Multiple Circuits/Poles}

The script accounts for multiple circuits (AC) or poles (DC) by multiplying losses by the number of circuits/poles.

\subsection{Reconductoring: Old Voltage, New Resistance}

For reconductoring projects, physical towers (and voltage clearances) are unchanged, so the script uses the \emph{old} configuration's voltage for phase current. Conductor resistance comes from the \emph{new} configuration (new conductors). Old category is built from \texttt{old\_capacity\_mw}, \texttt{old\_conductor\_type}, \texttt{old\_ac\_dc}, and \texttt{get\_converter\_type(old\_ac\_dc, ...)}.

\subsection{Standalone vs. Library Use}

This script can be run standalone (displays results via \texttt{print\_results}) or imported for \texttt{get\_total\_energy\_losses()}. The underlying calculation functions (phase current, full load adjustment, line losses, converter losses) live in \texttt{calculation\_utils.py} for reuse.
