\section{Introduction}

The \texttt{path\_config.py} module provides centralized path configuration for CTCC scripts. It defines absolute paths based on the location of \texttt{path\_config.py} (inside \texttt{scripts/}) so that YAML config and output directories are resolved consistently regardless of the current working directory. There are no environment overrides; paths are derived from \texttt{Path(\_\_file\_\_).parent.absolute()}.

\section{Method Overview}

\subsection{Purpose}

\begin{enumerate}
    \item Define \texttt{SCRIPT\_DIR} as the directory containing \texttt{path\_config.py} (i.e.\ \texttt{scripts/}).
    \item Define \texttt{PROJECT\_ROOT} as the parent of \texttt{SCRIPT\_DIR} (the CTCC project root).
    \item Define \texttt{YAMLS\_DIR} = \texttt{PROJECT\_ROOT / "yamls"} (YAML configuration files).
    \item Define \texttt{OUTPUTS\_DIR} = \texttt{PROJECT\_ROOT / "outputs"} (CSV and JSON output files).
    \item Define \texttt{SCRIPTS\_DIR} = \texttt{SCRIPT\_DIR} (same as \texttt{scripts/}).
    \item Export \texttt{YAMLS\_DIR}, \texttt{OUTPUTS\_DIR}, \texttt{PROJECT\_ROOT}, \texttt{SCRIPTS\_DIR} via \texttt{\_\_all\_\_}.
\end{enumerate}

\subsection{Calculation Approach}

Paths only; no cost/benefit logic. All paths are \texttt{pathlib.Path} instances. Base directory is the script location, not the current working directory, so running \texttt{python scripts/build\_costs.py} from the project root or from elsewhere yields the same \texttt{YAMLS\_DIR} and \texttt{OUTPUTS\_DIR} relative to the project.

\subsection{Inputs and Outputs}

\textbf{Inputs:}
\begin{itemize}
    \item None (no env vars or function arguments); paths are computed from \texttt{\_\_file\_\_}.
\end{itemize}

\textbf{Outputs:}
\begin{itemize}
    \item Module-level constants: \texttt{YAMLS\_DIR}, \texttt{OUTPUTS\_DIR}, \texttt{PROJECT\_ROOT}, \texttt{SCRIPTS\_DIR}. Used by \texttt{yaml\_loaders}, \texttt{weighted\_miles}, \texttt{build\_costs}, \texttt{row\_costs}, \texttt{insurance\_costs}, \texttt{environmental\_mitigation}, \texttt{oandm}, \texttt{energy\_losses}, \texttt{bcr\_calculator}, \texttt{csv\_output\_manager}, \texttt{smart\_loaders}, \texttt{revenue}.
\end{itemize}

\subsection{Integration with Other Scripts}

\begin{itemize}
    \item \texttt{yaml\_loaders.py} --- Uses \texttt{YAMLS\_DIR} for all YAML file paths (e.g.\ \texttt{YAMLS\_DIR / "01\_project\_technical\_details.yaml"}).
    \item \texttt{weighted\_miles.py} --- \texttt{YAMLS\_DIR / "02\_project\_physical\_details.yaml"}.
    \item \texttt{build\_costs.py}, \texttt{row\_costs.py}, \texttt{insurance\_costs.py}, \texttt{environmental\_mitigation.py}, \texttt{oandm.py}, \texttt{energy\_losses.py} --- \texttt{YAMLS\_DIR} for config YAMLs.
    \item \texttt{bcr\_calculator.py} --- \texttt{OUTPUTS\_DIR} for \texttt{batch\_summary.csv}, \texttt{YAMLS\_DIR} for BCR config YAML.
    \item \texttt{csv\_output\_manager.py} --- \texttt{OUTPUTS\_DIR} (default output dir), \texttt{YAMLS\_DIR} where used.
    \item \texttt{smart\_loaders.py} --- \texttt{YAMLS\_DIR} when in YAML mode for \texttt{get\_project\_data\_raw}, \texttt{get\_financing\_data\_raw}, \texttt{get\_physical\_data\_raw}.
    \item \texttt{revenue.py} --- \texttt{OUTPUTS\_DIR} for \texttt{batch\_summary.csv} and JSON output paths.
\end{itemize}

\section{Key Functions}

There are no callable functions; only module-level constants are defined.

\subsection{Constants}

\textbf{Key logic (path resolution):}
\begin{lstlisting}
SCRIPT_DIR = Path(__file__).parent.absolute()
PROJECT_ROOT = SCRIPT_DIR.parent
YAMLS_DIR = PROJECT_ROOT / "yamls"
OUTPUTS_DIR = PROJECT_ROOT / "outputs"
SCRIPTS_DIR = SCRIPT_DIR
__all__ = ["YAMLS_DIR", "OUTPUTS_DIR", "PROJECT_ROOT", "SCRIPTS_DIR"]
\end{lstlisting}

\begin{itemize}
    \item \texttt{SCRIPT\_DIR} --- Absolute path to \texttt{scripts/} (directory containing \texttt{path\_config.py}).
    \item \texttt{PROJECT\_ROOT} --- Absolute path to the CTCC project root (parent of \texttt{scripts/}).
    \item \texttt{YAMLS\_DIR} --- \texttt{PROJECT\_ROOT / "yamls"}; used for all YAML config file paths.
    \item \texttt{OUTPUTS\_DIR} --- \texttt{PROJECT\_ROOT / "outputs"}; used for \texttt{batch\_summary.csv}, \texttt{json\_output\_*.json}, \texttt{ctcc\_results\_*.json}.
    \item \texttt{SCRIPTS\_DIR} --- Same as \texttt{SCRIPT\_DIR}; alias for the scripts directory.
\end{itemize}

\section{Example}

Typical usage in a script:
\begin{lstlisting}
from path_config import YAMLS_DIR, OUTPUTS_DIR
with open(YAMLS_DIR / "02_project_physical_details.yaml", "r") as f:
    data = yaml.safe_load(f)
# ...
output_path = OUTPUTS_DIR / "batch_summary.csv"
\end{lstlisting}

If \texttt{path\_config.py} is at \texttt{/path/to/CTCC/scripts/path\_config.py}, then \texttt{PROJECT\_ROOT} is \texttt{/path/to/CTCC}, \texttt{YAMLS\_DIR} is \texttt{/path/to/CTCC/yamls}, and \texttt{OUTPUTS\_DIR} is \texttt{/path/to/CTCC/outputs}, regardless of \texttt{os.getcwd()}.
