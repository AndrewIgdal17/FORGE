CTCC Input Tabs — Inner Content Patterns

Every sub-tab and what's currently inside it. We'll redesign these in batches.

1. Project Identity

Technology
Guide banner · Collapsible "Technology Configuration" · Form grid (5 fields: type, AC/DC, MW, voltage, reconductor toggle) · "Line Utilization" section with slider · Design Comparison section (conditional)
Timeline
Guide banner · "Project Timing" section · Form grid (3 fields: construction years, delay years, lifetime)

2. Equipment

Conductor Details
Guide banner · Conductor Type dropdown · Read-only params table (spec, voltage, phases, resistance) · Source citation footer
Structure Details
Guide banner · Read-only params table (structures per mile by terrain, cost per structure)
Converter Details
Guide banner · Converter Type dropdown · Read-only params table (loss %, cost) · DC-only conditional

3. Routing & Terrain

Terrain Mix
Guide banner · Validation banner (⚠️) · Editable terrain table (9 terrains × miles + multipliers) · Calculated total row · Construction-type filtering
Rights of Way
Guide banner · "Uses Existing ROW" toggle · Editable ROW table (greenfield or existing-ROW variant) · Terrain-filtered rows

4. Benefits

Economic Details
Guide banner · Form grid (electricity price, VoLL) · Standard collapsible sections
System Constraints
Guide banner · Form grid (congestion price, curtailment price, hours, flow factor)

5. Financial

Rates
Guide banner · Custom split-grid panel (WACC, discount rate, inflation, base year) · Locked "Real WACC" display · Revenue Requirements toggle
AFUDC
Guide banner · Cost timing grid (editable % splits across categories) · AFUDC enable toggle · Locked discount rate display

6. Capital Costs

Conductor / Structure / Converter
L4 pill tabs · Guide banner per L4 · Editable cost tables (per-terrain costs) · Lock/unlock mechanics · Construction-type filtering · Contingency fields

7. Operating Costs

Insurance
Guide banner · Insurable assets table (rate × build cost → premium) · 3 construction types
Maintenance (L4: Conductor / Structure / Converter)
L4 pill tabs · Guide banner per L4 · Editable maintenance tables per terrain · Lock/unlock · Contingency fields
Vegetation Management
Guide banner · Editable veg mgmt table (cost/mile × terrain) · Lock/unlock · Construction-type filtered

8. Risk

Wildfire Risk (L4: Parameters / Terrain Rates)
L4 pill tabs · Guide banner · Form fields (ignition rate, severity, growth) · Per-terrain ignition table · Construction-type filtering
Outage Risk (L4: Parameters / VoLL Tiers)
L4 pill tabs · Guide banner · Form fields (outage rate, duration, capacity-at-risk) · VoLL tiers table · Load-shed + redispatch decomposition

9. Emissions

Energy (Emissions)
Guide banner · Emissions impact panel with Chart.js pie chart · Restructured intensity table (CO₂, SOₓ, NOₓ per fuel) · SCC fields · Chemical subscripts
Emissions (loss-compensation)
Guide banner · Standard form fields (emission factors)

10. Energy Mix

Project Energy Mix
Guide banner · Fuel mix preset dropdown · Compact fuel mix table (8 fuels × % + rate of change) · Sum validation row
Counterfactual Energy Mix
Same structure as project mix · Represents the "no-line" baseline
