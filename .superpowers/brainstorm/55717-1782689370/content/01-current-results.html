Current Rendering Style

Each results sub-item renders as raw DOM-constructed divs with inline styles. No design system components (unlike the input panel redesign that added .ctcc-params-card, .ctcc-table-card, etc.).

  • Overview: 2×2 grid of hero metric cards + collapsible BCR perspectives
  • Cost buckets: Taxonomy-driven detail rows (label + PV value) grouped by bucket
  • Benefit buckets: Similar taxonomy-driven rows with benefit values
  • Styles: Mostly inline CSS on createElement() calls, not using design tokens
