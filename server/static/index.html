Differences vs a chosen baseline column are pairwise changes in each metric (ΔNB and ΔCP:B in the paper appendix). Enable Show Δ vs baseline in the toolbar after selecting scenarios. Sign convention: Δ is always scenario value − baseline value. For benefits and net benefit, positive Δ means the scenario scores higher (better). For cost PV rows (capital, emissions, risk, etc.), positive Δ means the scenario is more expensive; negative Δ means cheaper (avoided cost). For ratios such as BCR, positive Δ means the scenario’s ratio is numerically higher. Note for paper readers: the appendix defines ΔCP:B = baseline − scenario (avoided-cost convention); cost Δ in this table uses the opposite sign so every row follows the same scenario − baseline direction.
